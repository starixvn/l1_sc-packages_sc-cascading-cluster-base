## Feature Processing Sub-Flow

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                        RAGE METER FEATURE PROCESSING                         │
│                                                                              │
│   ┌────────────────────────────────────────────────────────────────────┐    │
│   │  Win Detected → Add Link Count to Rage Counter                     │    │
│   └────────────────────────────────┬───────────────────────────────────┘    │
│                                    │                                         │
│                                    ▼                                         │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │  Check: rageCounter >= stageThreshold[currentStage + 1]?            │   │
│   └───────────────┬─────────────────────────────────────┬───────────────┘   │
│                   │ YES                                 │ NO                 │
│                   ▼                                     ▼                    │
│   ┌───────────────────────────────┐        ┌────────────────────────┐       │
│   │  Push Stage to Feature Queue  │        │  Continue Normal Flow  │       │
│   │  Increment Current Stage      │        └────────────────────────┘       │
│   └───────────────┬───────────────┘                                         │
│                   │                                                          │
│                   ▼ (check next stage)                                       │
│                                                                              │
│   ════════════════════════════════════════════════════════════════════      │
│                                                                              │
│   After Cascade Completes (no more wins):                                    │
│                                                                              │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │  While Feature Queue Not Empty:                                     │   │
│   └───────────────┬─────────────────────────────────────────────────────┘   │
│                   │                                                          │
│                   ▼                                                          │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │  Pop Stage from Queue → Execute Stage Processor                     │   │
│   └───────────────┬─────────────────────────────────────────────────────┘   │
│                   │                                                          │
│       ┌───────────┼───────────┬───────────┬───────────┐                     │
│       ▼           ▼           ▼           ▼           ▼                     │
│   ┌───────┐   ┌───────┐   ┌───────┐   ┌───────┐   ┌───────┐                │
│   │Stage 1│   │Stage 2│   │Stage 3│   │Stage 4│   │Stage N│                │
│   │6 Rand │   │3x3    │   │2 Cols │   │Symbol │   │Custom │                │
│   │Detonate│  │Area   │   │Detonate│  │Replace│   │Effect │                │
│   └───┬───┘   └───┬───┘   └───┬───┘   └───┬───┘   └───┬───┘                │
│       │           │           │           │           │                     │
│       └─────┬─────┴─────┬─────┴─────┬─────┴─────┬─────┘                     │
│             │           │           │           │                            │
│             ▼           ▼           ▼           ▼                            │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │  Cascade Board → Record Tumble → Check for New Wins                 │   │
│   └───────────────┬─────────────────────────────────────────────────────┘   │
│                   │                                                          │
│                   ▼                                                          │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │  If New Wins → Back to Main Tumble Loop                             │   │
│   │  If No Wins → Process Next Queued Feature (if any)                  │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
```

## Free Spin Chain Flow

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         FREE SPIN CHAIN FLOW                                 │
│                                                                              │
│   Normal Game Round                                                          │
│         │                                                                    │
│         ▼ (3+ scatters detected)                                             │
│   ┌──────────────────┐                                                       │
│   │  Trigger Free    │                                                       │
│   │  Spins           │                                                       │
│   └────────┬─────────┘                                                       │
│            │                                                                 │
│            ▼                                                                 │
│   ┌──────────────────────────────────────────────────────────────────┐      │
│   │  Initialize Free Spin State:                                      │      │
│   │  - Set Max Win Cap                                                │      │
│   │  - Initialize Grid Multipliers (1 for Super, -1 for Normal)       │      │
│   │  - Reset Rage Meter                                               │      │
│   │  - Set Available Free Spin Count                                  │      │
│   └────────────────────────────────┬─────────────────────────────────┘      │
│                                    │                                         │
│   ╔════════════════════════════════▼═════════════════════════════════════╗  │
│   ║                     FREE SPIN LOOP                                   ║  │
│   ║                                                                      ║  │
│   ║   ┌──────────────────┐                                               ║  │
│   ║   │  Generate Free   │ ← Use FG Reels (normal or super weight)       ║  │
│   ║   │  Spin Board      │                                               ║  │
│   ║   └────────┬─────────┘                                               ║  │
│   ║            │                                                         ║  │
│   ║            ▼                                                         ║  │
│   ║   ┌──────────────────┐                                               ║  │
│   ║   │  Process Tumbles │ ← Preserves rage meter & multipliers          ║  │
│   ║   │  (Same as Normal)│                                               ║  │
│   ║   └────────┬─────────┘                                               ║  │
│   ║            │                                                         ║  │
│   ║            ▼                                                         ║  │
│   ║   ┌──────────────────┐                                               ║  │
│   ║   │  Update State:   │                                               ║  │
│   ║   │  - Grid Mults    │                                               ║  │
│   ║   │  - Rage Meter    │                                               ║  │
│   ║   │  - Remaining Win │                                               ║  │
│   ║   └────────┬─────────┘                                               ║  │
│   ║            │                                                         ║  │
│   ║            ▼                                                         ║  │
│   ║   ┌─────────────────────────────────────────────────────────┐        ║  │
│   ║   │  Check: More Scatters? → Add More Free Spins            │        ║  │
│   ║   └────────────────────────────────┬────────────────────────┘        ║  │
│   ║                                    │                                 ║  │
│   ║            ┌───────────────────────┴────────────────────────┐        ║  │
│   ║            │                                                │        ║  │
│   ║            ▼                                                ▼        ║  │
│   ║   ┌─────────────────┐                              ┌──────────────┐  ║  │
│   ║   │  Decrement      │                              │  Max Win     │  ║  │
│   ║   │  Available      │                              │  Reached?    │  ║  │
│   ║   │  Free Spins     │                              └──────┬───────┘  ║  │
│   ║   └────────┬────────┘                                     │          ║  │
│   ║            │                                              │          ║  │
│   ║            ▼                                              ▼          ║  │
│   ║   ┌─────────────────┐                              ┌──────────────┐  ║  │
│   ║   │  More Free      │                              │  STOP CHAIN  │  ║  │
│   ║   │  Spins?         │                              │  Force End   │  ║  │
│   ║   └───┬─────────┬───┘                              └──────────────┘  ║  │
│   ║       │ YES     │ NO                                                 ║  │

│                                    ▼                                         │

│   │  End Free Spin Chain:                                             │      │

│                                                                              │
```
